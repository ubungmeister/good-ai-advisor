# Good AI Advisor UI

The React + TypeScript client for Good AI Advisor.

## Development

```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

Set `VITE_API_URL` in `.env` to the running FastAPI API (by default,
`http://localhost:8000`).

Useful commands:

```powershell
npm run lint
npm run build
```

For the full project overview and backend setup, see the
[root README](../README.md).
